# 酒馆衣橱插件 - 设计文档

**日期：** 2026-06-07
**状态：** 待实施

---

## 概述

一个酒馆助手加载的独立插件，用于管理角色的衣服和发型。提供图形化界面，每个物品配有图片，勾选后在 AI 生成时自动将对应描述注入提示词。

## 架构

```
酒馆助手 JSON 配置文件 (wardrobe-plugin.json)
└── content (内联 JS)
    ├── 浮窗 UI 层    —— HTML/CSS 注入 + DOM 渲染
    ├── 数据管理层    —— CRUD 操作、localStorage 读写
    └── 提示词注入层  —— 监听发送事件、拼接文本
```

- **运行环境：** 纯浏览器端，无后端依赖
- **加载方式：** 酒馆助手读取本地 JSON 文件，执行 `content` 字段中的 JS
- **存储：** localStorage（key: `wardrobe_plugin_data`），同时利用酒馆助手 JSON 的 `data` 字段作为启动时的同步源

## UI 布局

采用 **左右分栏** 布局（方案 A），独立浮窗面板。

### 主界面

| 组件 | 说明 |
|---|---|
| 浮窗标题栏 | 显示"衣橱管理"，可拖拽移动，右上角关闭按钮 |
| 触发按钮 | 页面右下角固定 👗 按钮，点击切换浮窗显示/隐藏 |
| 左侧分类列表 | 衣服/发型两大类，各有子分类。点击切换。底部"+"添加分类 |
| 右侧物品网格 | 每项显示缩略图、名称、描述摘要。选中项紫色边框高亮。2列布局 |
| 添加物品按钮 | 右上角"+"添加，弹出表单：名称、图片URL、描述、分类选择 |
| 管理按钮 | 每个物品卡片上有编辑 ✏️ 和删除 🗑️ 按钮 |

### 状态表示

- 未选中：灰色边框，图片正常显示
- 选中：紫色边框 + 浅紫背景 + "✓ 已选中"标记
- 图片加载失败：占位图 🖼️

## 数据结构

### 存储位置

localStorage key: `wardrobe_plugin_data`

### 数据模型

```json
{
  "categories": {
    "clothes": ["日常", "正装", "睡衣", "战斗服"],
    "hairstyles": ["长发", "短发", "盘发"]
  },
  "items": [
    {
      "id": "uuid-xxxx",
      "type": "clothes",
      "name": "黑色晚礼服",
      "imageUrl": "https://example.com/dress.png",
      "promptText": "穿着黑色丝质晚礼服，裙摆曳地",
      "category": "正装"
    }
  ],
  "selected": {
    "clothes": "uuid-xxxx",
    "hairstyle": "uuid-yyyy"
  }
}
```

### 字段说明

| 字段 | 类型 | 说明 |
|---|---|---|
| `id` | UUID v4 | 唯一标识 |
| `type` | `"clothes"` \| `"hairstyle"` | 物品类型 |
| `name` | string | 物品名称 |
| `imageUrl` | string | 图片 URL |
| `promptText` | string | 注入提示词的描述文字 |
| `category` | string | 所属分类 |
| `selected.clothes` | string \| null | 当前选中的衣服 ID |
| `selected.hairstyle` | string \| null | 当前选中的发型 ID |

### 选择规则

- 衣服和发型各自单选（各只能选一个）
- 选中另一件时自动取消之前的选择

## 提示词注入机制

### 触发时机

用户点击酒馆发送按钮或按 Enter 发送消息时。

### 注入格式

在原有提示词末尾追加：

```
[原有提示词]

（外表描写：{发型描述}，{衣服描述}）
```

- 只选了一种 → 只追加对应描述
- 都没选 → 不追加
- 描述为空 → 只追加物品名称

### 技术实现

- 监听发送按钮的 `click` 事件（捕获阶段）：先修改输入框内容（追加描述），再让原事件正常继续发送
- 同时监听输入框的 `keydown`（Enter 键，非 Shift+Enter）作为补充
- 修改输入框值后不阻止事件传播，酒馆正常发送修改后的内容

## 交互流程

1. 用户点右下角 👗 → 浮窗弹出
2. 点左侧分类 → 右侧过滤显示该分类物品
3. 点物品卡片 → 选中/取消（同一类型内单选）
4. 选好后关闭浮窗 → 正常聊天 → 发送时自动注入

## 数据导入导出

- **导出：** 浮窗设置按钮 → 导出 JSON → 浏览器下载文件
- **导入：** 浮窗设置按钮 → 导入 JSON → 选择文件 → 验证格式 → 合并/替换现有数据
- **格式验证：** 导入时检查 JSON 结构，不合法则弹窗提示并拒绝

## 错误处理

| 场景 | 处理方式 |
|---|---|
| 图片加载失败 | 显示占位图 🖼️，卡片标记为"图片加载失败" |
| 物品描述为空 | 注入时只追加名称，正常发送不报错 |
| localStorage 满 | 弹窗提醒清理旧数据或导出备份 |
| 无分类时添加物品 | 自动创建"默认"分类 |
| 导入 JSON 格式错误 | 弹窗提示具体错误信息，不覆盖现有数据 |
| 酒馆 DOM 变化 | 静默失效，不影响聊天功能 |
| 浮窗拖出屏幕 | 限制拖拽范围在可视区域内 |
| 多个发送按钮匹配 | 取第一个匹配的元素 |

## 技术约束

- 所有代码内联在 JSON 的 `content` 字段中
- 不依赖外部框架（纯原生 JS + CSS）
- 不依赖酒馆内部 API（只操作标准 DOM）
- 兼容 Chrome 浏览器
- 图片仅支持 URL 引用（用户自行提供）
